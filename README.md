# calculator
I built a calculator using Python, HTML, CSS, and Flask framework. 
- Link: https://web-calculator-qzde.onrender.com/

**How to Use**
- To use the calculator, just enter the first number in the top box and the second number in the second box and select an operation(addition, subtraction, multiplication, or division). Then click calculate!

## Development
**Process** 
- Making this calculator required me to combine my knowledge across fields to ensure it worked smoothly. I already knew how to use Python logic to create a calculator that would take user input and apply mathematical formulas based on that input and display the answer. I also knew how to make webpages using HTML and style them using CSS. However, the Python calculator would not work as a webpage because it was only usable by opening the file on a laptop. For this reason, I had to create a webpage that would display this calculator so that it would be accessible on a browser rather than requiring a user to download a file. I learned how to use Flask to connect the Python backend to the webpage and handle user input, and had to move from VS Code to GitHub Codespaces to successfully deploy the calculator. To make it shareable as an independent link, I used Render to host it live on the cloud.

**New skills**
- combining multiple coding languages(HTML, CSS, Python) into a working application
- using Flask framework to handle user requests
- learned how to deploy the app using cloud container environments 

**Challenges and Troubleshooting** 
- Some issues I ran into included the problem with VS Code as it, along with the Windows software on my laptop, would not allow me to deploy the app through a terminal. It would not recognize the Python application downloaded on my laptop so I moved to GitHub which was able to successfully run the code and display the working calculator in a new tab.

**Why did I build this?**
1) This whole week I've been having finals and while studying for my math one, my calculator died all of a sudden because it was solar powered. I had to use my phone's calculator to solve problems instead which wasn't the best strategy because I kept getting distracted and ended up doing something else on my phone instead of actually studying. I remembered how I learned to code a calculator in Python class a couple years ago and wanted to make something that would actually work on a webpage, not just a desktop application. I was also thinking of this week's task on Shipyard where we had to learn a new skill and thought this was the perfect opportunity.
2) I wanted the chance to build and expand on a project that uses Python logic especially since I've mostly been focusing on HTML and CSS for a while.

**Possible Future Goals...?**
I might consider adding more mathematical operations to the calculator especially since it only does the four basic functions that most people can do in their heads/on paper. The only time I use a calculator is when I do my math homework for things like trignometry, so it would be nice to make a calculator that can solve more complex problems.
