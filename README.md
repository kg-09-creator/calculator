# calculator
I built a calculator using Python, HTML, CSS, and Flask framework. 
- Link: https://web-calculator-qzde.onrender.com/

## Development
**Process** 
- Making this calculator required me to combine my knowledge across fields to ensure it worked smoothly. I already knew how to use Python logic to create a calculator that would take user input and apply mathematical formulas based on that input and display the answer. I also knew how to make webpages using HTML and style them using CSS. However, the Python calculator would not work as a webpage because it was only usable by opening the file on a laptop. For this reason, I had to create a webpage that would display this calculator so that it would be accessible on a browser rather than requiring a user to download a file. I had to learn how to use Flask frameworks to process incoming requests to ensure this would work, and had to move from VS Code to GitHub Codespaces to successfully deploy the calculator. To make it shareable as an independent link, I used Render to host it live on the cloud.

**Issues** 
- Some issues I ran into included the problem with VS Code as it, along with the Windows software on my laptop, would not allow me to deploy the app through a terminal. It would not recognize the Python application downloaded on my laptop so I moved to GitHub which was able to successfully run the code and display the working calculator in a new tab.
