# calculator
I built a calculator using Python, HTML, CSS, and Flask framework. 
- Link: https://web-calculator-qzde.onrender.com/

**How to Use**
- To use the calculator, just enter the first number in the top box and the second number in the second box and select an operation(addition, subtraction, multiplication, or division). Then click calculate!

## Development
**Process** 
- Making this calculator required me to combine my knowledge across fields to ensure it worked smoothly. I already knew how to use Python logic to create a calculator that would take user input and apply mathematical formulas based on that input and display the answer. I also knew how to make webpages using HTML and style them using CSS. However, the Python calculator would not work as a webpage because it was only usable by opening the file on a laptop. For this reason, I wanted to create a webpage that would display this calculator so that it would be accessible on a browser rather than requiring a user to download a file. 

**Challenges and Troubleshooting** 
- Some issues I ran into included the problem with VS Code as it, along with the Windows software on my laptop, would not allow me to deploy the app through a terminal. It would not recognize the Python application downloaded on my laptop so I moved to GitHub which was able to successfully run the code and display the working calculator in a new tab.

**Why did I build this?**
1) This whole week I've been having finals and while studying for my math one, my calculator died all of a sudden because it was solar powered. I had to use my phone's calculator to solve problems instead which wasn't the best strategy because I kept getting distracted and ended up doing something else on my phone instead of actually studying. I remembered how I learned to code a calculator in Python class a couple years ago and wanted to make something that would actually work on a webpage, not just a desktop application. 

**Possible Future Goals...?**
I might consider adding more mathematical operations to the calculator especially since it only does the four basic functions that most people can do in their heads/on paper. The only time I use a calculator is when I do my math homework for things like trignometry, so it would be nice to make a calculator that can solve more complex problems.
